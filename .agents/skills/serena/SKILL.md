# Serena: Búsqueda Inteligente

Usa esta guía para realizar búsquedas eficientes en el codebase.

## Instrucciones de uso
- Serena te ayuda a buscar símbolos y componentes del sistema.
- Si necesitás encontrar dónde se define una función, componente o referencia, usá herramientas de búsqueda recursivas o grep_search en el codebase en lugar de leer archivos al azar.
