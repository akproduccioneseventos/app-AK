# Asistente AK — Guía de Uso

## ¿Qué es el Asistente AK?

El Asistente AK es un copiloto inteligente integrado en la app de AK Producciones. Permite gestionar tu negocio de eventos usando lenguaje natural: crear presupuestos, registrar clientes, importar datos desde fotos y más.

## Cómo importar presupuestos desde foto/PDF

1. Abrí el Asistente AK (botón flotante abajo a la derecha)
2. Tocá el ícono de 📎 (clip) para adjuntar un archivo
3. Seleccioná la foto o PDF del presupuesto
4. El asistente analizará el archivo y extraerá los datos
5. Si la extracción es exitosa, se crea un presupuesto borrador

### ¿Qué pasa cuando falla la extracción?

- **Archivo borroso o ilegible**: El asistente te pedirá una imagen más clara
- **No se detectan servicios**: No se crea presupuesto. Te sugiere cargarlo manualmente
- **Datos parciales**: Se crea un borrador marcado como incompleto para que lo completes
- **Error de conexión con la IA**: Mensaje simple pidiendo que reintentes

### ¿Qué hacer con borradores incompletos?

Si el asistente creó un borrador sin todos los servicios:

1. Andá a **Presupuestos** → buscá el presupuesto marcado como "Borrador"
2. Hacé clic en "Editar"
3. Agregá los servicios faltantes manualmente
4. Guardá los cambios

## Troubleshooting

### "No pude procesar tu mensaje"
- **Causa**: Problema temporal con el servicio de IA
- **Solución**: Esperá unos minutos y volvé a intentar

### "No pude leer el archivo automáticamente"
- **Causa**: La imagen es borrosa, está cortada, o el formato no se reconoce
- **Solución**: Subí una foto más clara, con buena iluminación, o cargá los datos manualmente

### "No se detectaron servicios suficientes"
- **Causa**: La IA no pudo extraer precios/servicios del archivo
- **Solución**: Cargá los datos manualmente desde /presupuestos/nuevo

### El asistente no responde
- **Causa**: Puede haber un problema de conexión
- **Solución**: Verificá tu conexión a internet y recargá la página

### El presupuesto se creó sin servicios
- **Nota**: El sistema ahora valida que haya al menos 1 servicio con precio antes de crear. Si ves un borrador incompleto antiguo, editalo manualmente.
