# **App Name**: Presupuestador AK Producciones

## Core Features:

- Fast Invoice Creation: Create, edit, and send invoices quickly using a simplified interface.
- Invoice Status Tracking: Manage and track invoice status (sent, viewed, paid, overdue) visually.
- Receipt Auto-Fill: Use AI to automatically extract information from uploaded receipts to fill in invoice details.
- PDF Invoice Generation: Generate professional-looking PDF invoices that can be easily downloaded or emailed.
- Customer Management: Save customer information for repeat billing
- Template Customization: Allow customization of invoice templates, including logo upload, and color theming.

## Style Guidelines:

- Primary color: Red (#FF0000) to inspire trust and professionalism. This particular hue implies cleanliness and accuracy, which is what a user wants in a billing app.
- Background color: White (#FFFFFF), provides a clean, neutral backdrop.
- Accent color: Red (#FF0000) to indicate successfully paid invoices or completed actions.
- Font pairing: 'Inter' sans-serif for body text because it is modern, readable, and professional; 'Belleza' serif for headlines, which pairs well with 'Inter' due to its subtle and modern character; gives an aura of fashion, art and design.
- Use line-based icons from a consistent set (e.g., Font Awesome or Material Design Icons) for clarity.
- Ensure a clear visual hierarchy, emphasizing the most important actions (e.g., 'Create Invoice').
